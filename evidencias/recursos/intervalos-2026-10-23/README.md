# Informes anteriores a activar PSI

Resultados del analizador nuevo sobre las capturas del commit 9dd71f3.
Cada perfil QEMU tiene 26 muestras y 25 intervalos calculables de VM/discos.
Los archivos originales de esos invitados descartables se conservan bajo
generico/ y pc/. Los contadores PSI siguen ausentes: no representan cero.
El informe fisico previo tiene 39 muestras y cero capturas completas del
protocolo de recursos; no se calculan tasas. Su fuente privada no se copia:
origenes.json conserva nombre/hash y la salida solo incluye el resumen.
No hubo escrituras en los informes originales. Estos resultados no describen
el kernel posterior con PSI ni el rendimiento del SSD fisico.
